# EV Charging Patterns & Efficiency Dashboard

This project is a data analysis dashboard created using the **EcoCharge Solutions Dataset**.

It provides key insights into how Electric Vehicle (EV) owners use charging infrastructure and the efficiency of those charging sessions.

## 🎯 Project Goal

To analyze and visualize EV charging behavior and efficiency metrics to inform strategic decisions regarding infrastructure, service improvements, and user engagement.

## 📊 Key Insights & Metrics

The project focuses on answering critical questions about EV charging, including:

| Category | Key Metrics Analyzed |
| :--- | :--- |
| **Efficiency** | Charging Efficiency Rate and its quality category (`Outstanding`, `Superior`, `Acceptable`, `Low`). |
| **Usage Patterns** | When and where users charge (`Time of Day`, `Charging Station Location`). |
| **User Segmentation** | Charging habits segmented by `User Type` (`Commuter`, `Casual Driver`, `Long-Distance Traveler`). |
| **Equipment** | Performance comparison across different `Charger Types` (`Standard`, `DC Fast`, `Enhanced`). |

## 📁 Repository Structure

The core files relevant to the analysis are:

* **`Final_Dashboard.xlsx - EcoCharge Solutions Dataset.csv`**: The raw data containing detailed records for each charging session.
* **`Final_Dashboard.xlsx - Data Description.csv`**: A glossary defining all the variables (e.g., `Energy Consumed (kWh)`, `State of Charge (Start %)`).
* **`Final_Dashboard.xlsx`**: Pre-aggregated data used to build the visualizations in the final dashboard.
